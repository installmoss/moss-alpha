### What is Moss Alpha?

Moss Alpha is a **quiet alpha** skill designed for Bankr agents.  

It focuses on finding tokens and setups that most people overlook — opportunities with low noise, healthy structure, and slow but steady growth signals.

No hype. No loud calls. Just calm, structured research.

---

### Install

Copy and paste this into your Bankr agent:

```bash
install the skill from https://github.com/installmoss/moss-alpha
```

---

### Features

- Low-noise opportunity discovery
- Quiet accumulation detection
- Healthy structure over pure momentum
- Calm, non-FOMO response style
- Clear risk framing
